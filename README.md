A newspaper-poster entry that sums up the world news of Thursday 19 November 2026 in one 1024×1024 image: Grand Theft Auto VI beginning its global rollout after a 13-year wait, the EU's proposed €45bn loan for Ukraine, NASA's Voyager 1 reaching one light-day from Earth, Hakeem Jeffries nominated to be the first African-American Speaker of the US House, Cyclone Akvan nearing India's east coast, and Xi Jinping's call for open trade at the APEC summit in Shenzhen. The artwork is drawn in poster.html (inline CSS and SVG) and rendered to entry.png; main.ts copies that image to the output directory as entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
